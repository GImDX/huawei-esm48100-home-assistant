# Security policy

## Reporting a vulnerability

Please report security issues through
[GitHub private vulnerability reporting](https://github.com/GImDX/huawei-esm48100-hacs/security/advisories/new).
Do not include Home Assistant diagnostics, credentials, private endpoints,
battery serial numbers, bar codes, or unredacted captures in a public issue.

For ordinary integration bugs, use the public issue tracker after removing
identifying information.

## Hardware safety

Advanced control entities are disabled by default. Only enable them after
confirming the battery model, firmware, wiring, and communication parameters.
